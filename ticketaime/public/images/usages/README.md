# Mises en situation

Ces neuf visuels photoréalistes ont été générés pour la landing **LE MONDE AIME**.
Ils illustrent des personnes présentant une pièce sur leur téléphone dans le
contexte de chaque usage. Ils ne représentent pas des clients ni des témoignages.

Les fichiers WebP sont optimisés pour une présentation pleine largeur. Les
descriptions alternatives et le cadrage responsive sont définis dans
`src/data/landing.ts`. Le détail de ces aperçus est accessible dans le pied de
page de la landing.
